# 🧮 Calculadora em Python — Imersão IA

> Projeto desenvolvido durante a Imersão de Inteligência Artificial para praticar lógica de programação, estruturas condicionais e integração entre o **Google AI Studio** e o **GitHub**.

---

## 📌 Sobre o Projeto

O objetivo deste projeto foi utilizar o Google AI Studio para gerar uma aplicação interativa em Python que executa as quatro operações matemáticas básicas: **adição**, **subtração**, **multiplicação** e **divisão**.

A aplicação inclui um terminal interativo e laboratórios práticos para explorar conceitos importantes da programação, como a prevenção de erros matemáticos (divisão por zero).

---

## 🛠️ Tecnologias Utilizadas

* **Python 3**: Linguagem de programação principal.
* **Google AI Studio**: Ferramenta de inteligência artificial utilizada na geração e estrutura do código.
* **GitHub**: Versionamento e hospedagem do código-fonte.

---

## 🚀 Funcionalidades

- [x] **Adição** (`+`)
- [x] **Subtração** (`-`)
- [x] **Multiplicação** (`*`)

---

## 🧠 Conceitos e Lógica de Programação Aprendidos

Durante o desenvolvimento e análise da aplicação, os seguintes componentes foram explorados:

1. **Funções (`def`)**: Isolamento da lógica de cada cálculo matemático em blocos reutilizáveis.
2. **Entrada e Saída (`input` e `print`)**: Recebimento dos dados digitados pelo usuário e exibição formatada dos resultados na tela.
3. **Estruturas Condicionais (`if` / `elif` / `else`)**: Tomada de decisão do programa para identificar qual operação deve ser executada com base na opção escolhida.
4. **Tipos de Dados (`float`)**: Conversão das entradas para permitir cálculos com números decimais.
5. **Tratamento de Exceções**: Verificação para impedir divisões por zero (`ZeroDivisionError`).
